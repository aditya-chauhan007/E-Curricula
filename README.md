# E-Curricula 📚

Welcome to the E-Curricula repository!

This repository contains a collection of PDF resources intended to help students access and download educational materials.

## 📂 Contents

* E-Curricula PDF documents
* Educational reference materials
* Additional resources added over time

## 📥 How to Download

### Download the Entire Collection

1. Open the repository on GitHub.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the ZIP file on your computer to access the PDFs.

### Download an Individual PDF

1. Open the PDF file you need.
2. Click the **Download raw file** button, or use the download option provided by GitHub.

## 🔄 Updates

New PDF files may be added periodically. Check the repository for the latest resources.
